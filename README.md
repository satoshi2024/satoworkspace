・給与所得の算出結果が影響する後続処理（課税計算パッケージ「B」内の以下の一連の計算処理、および「011_画面一覧」「031_一括処理一覧」「041_連携処理一覧」に定義された対象処理）について、既存ロジック自体の改修は行わないが、改正後の給与所得金額を用いて以下の通り期待どおりの結果となることを確認する。
  ① 所得金額合算処理：改正後の給与所得金額が総所得金額・合計所得金額へ正しく合算されること。
  ② 所得控除・課税標準額算出処理：合算後の所得金額をもとに、基礎控除・扶養控除等の適用判定および課税総所得金額が正しく算出されること。
  ③ 税額算出処理：更新された課税総所得金額を用いて、所得割額・均等割額（年税額）が正しく算出されること。
  ④ 登録・出力処理：算出された所得金額および税額が課税台帳へ正しく登録され、画面照会・帳票・連携データへ反映されること。
  ※なお、課税年度2026年度以前のデータについては、従来の計算結果から変化しないこともあわせて確認する。
