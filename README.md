2．給与所得算出結果の反映および業務上の変化
課税年度に応じた給与所得控除額を適用して給与所得金額を算出し、課税計算パッケージ（）内の総所得金額（合計所得金額）及び課税標準額（課税総所得金額）の算出処理へ引き渡す。
最低保障額の引上げにより、同一の給与収入金額であっても課税年度によって給与所得金額が減少し、それに伴い後続で算出される課税所得金額および個人住民税額（所得割額）が減少する。

（課税年度別の算出結果例：給与収入180万円・他所得および特定支出控除なしの場合）
・2026年度（令和8年度）：給与所得控除額 65万円 → 給与所得金額 115万円
・2027年度（令和9年度）：給与所得控除額 74万円（特例） → 給与所得金額 106万円
・2028年度（令和10年度）：給与所得控除額 74万円（特例） → 給与所得金額 106万円
・2029年度（令和11年度）：給与所得控除額 69万円（本則） → 給与所得金額 111万円
