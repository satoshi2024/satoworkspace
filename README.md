【処理内容】

・[対象ワーク名]（[テーブルID]）のレコード件数を取得する。

・取得件数が0件の場合、正常終了する。

・引数.帳票IDが「[帳票ID_1]」、「[帳票ID_2]」、「[帳票ID_3]」、「[帳票ID_4]」、「[帳票ID_5]」のいずれかの場合

　・[対象データ1]用ワークより[データ名1]CSVデータを作成する。

　　※関数「[関数名1]」を呼び出す。

・上記以外の場合

　・[対象データ2]用ワークより[データ名2]CSVデータを作成する。

　　※関数「[関数名2]」を呼び出す。

・処理結果が0以外の場合、戻り値を返して処理を終了する。

・処理結果をログに出力する。
